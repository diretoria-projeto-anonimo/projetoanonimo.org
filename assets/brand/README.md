# Kit vetorial — Projeto Anônimo

Ativos de identidade visual em SVG. Todos os arquivos foram produzidos com geometria vetorial, sem imagens raster incorporadas.

## Arquivos

- `projeto-anonimo-icon-dark.svg`: ícone colorido para uso principal em interfaces e redes sociais.
- `projeto-anonimo-icon-light.svg`: ícone monocromático suave para fundos claros.
- `projeto-anonimo-symbol.svg`: símbolo colorido com fundo transparente.
- `projeto-anonimo-logo-horizontal-on-light.svg`: assinatura horizontal para fundos claros.
- `projeto-anonimo-logo-horizontal-on-dark.svg`: assinatura horizontal para fundos escuros.
- `projeto-anonimo-logo-vertical.svg`: assinatura vertical para composições institucionais.
- `projeto-anonimo-monochrome-dark.svg`: símbolo monocromático escuro e transparente.
- `projeto-anonimo-monochrome-light.svg`: símbolo monocromático claro e transparente.
- `projeto-anonimo-favicon.svg`: versão simplificada para tamanhos pequenos.

## Paleta

- Verde quase preto: `#111B18`
- Verde institucional: `#0D4D44`
- Menta: `#D3EBD9`
- Superfície clara: `#F2FAF4`

## Tipografia

As assinaturas utilizam `IBM Plex Sans` com peso 600 e fallback para Arial/sans-serif. Antes do uso em materiais gráficos finais, confirme que a fonte IBM Plex Sans está instalada ou converta o texto em contornos na ferramenta de design.

## Regras essenciais

- Não distorcer, inclinar ou alterar as proporções do símbolo.
- Não modificar isoladamente a geometria de uma camada.
- Manter área de respiro ao redor da marca.
- Usar a versão clara somente sobre fundos que ofereçam contraste suficiente.
- Não incorporar fichas técnicas, datas ou metadados visuais ao logotipo.

## Referências conceituais

As imagens em `references/` registram a exploração visual feita durante o desenvolvimento da marca. Elas não são arquivos oficiais de logotipo e não devem substituir os SVGs deste diretório.

- `reference-01-brand-application-board.jpeg`: prancha de aplicações e direção visual.
- `reference-02-asset-system-board.jpeg`: estudo de organização do sistema de ativos.
- `reference-03-institutional-layered-concept.jpeg`: conceito institucional detalhado de arquitetura em camadas.
- `reference-04-generated-symbol-study.jpeg`: estudo raster usado como referência para o desenho vetorial.
